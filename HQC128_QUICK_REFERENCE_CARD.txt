┌──────────────────────────────────────────────────────────────────────────┐
│  HQC-128 数据流示例（Encapsulation）                                    │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  输入 (2281B)：m || pk || salt                                         │
│         ↓                                                               │
│    keccak_sponge_shake256_hqc128_g()                                   │
│         ↓                                                               │
│    ┌─ Absorb loop:                                                     │
│    │  块 1:  XOR state[0:136]   → f[1600]  ✓                          │
│    │  块 2:  XOR state[0:136]   → f[1600]  ✓                          │
│    │  ...                                                              │
│    │  块 16: XOR state[0:136]   → f[1600]  ✓                          │
│    │  块 17: XOR state[0:105]   → Padding  → f[1600]  ✓              │
│    └─                                                                  │
│         ↓                                                               │
│    Squeeze: state[0:64]                                                │
│         ↓                                                               │
│    输出 (64B)：theta                                                   │
│                                                                          │
│  关键参数：                                                             │
│  • Rate:          136 bytes (SHAKE256)                                 │
│  • Capacity:       64 bytes                                            │
│  • Padding byte:  0x1F (FIPS 202)                                     │
│  • 块数:           17 (2281/136 + 1)                                   │
│  • 每块 f[1600]:   ~5ms (@ 1MHz, Verilator)                          │
│  • 总耗时:         ~85ms (vs 纯软件 ~850ms)                           │
│                                                                          │
